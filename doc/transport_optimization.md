# 传输与模块化优化记录

基线为 `75023be947703564b2867678abbc576049a46ad0`。本轮重点是减少传输热路径重复计算，修正采样与浮点边界，并明确模块和存储契约。

## 已实施的改动

- 将公共库和传输聚合文件拆为数学、散射、分支选择、引导、介质、折射模块；把反射解码拟合系数从响应实现中分开。
- 移除没有入口的主射线 fallback、旧第一跳折射采样和输出、未调用的 NDF/双坐标统计辅助函数，以及无消费者的临时字段。
- 合并 GGX 的半向量、D、Smith 和 PDF 求值；反射与透射吞吐权重解析约分。透射不再计算随后会约掉的分布函数和折射 Jacobian。
- 第一跳只有选中 VNDF 提案才生成 GGX 法线；后续漫反射分支不生成 GGX 法线。
- 修正太阳及近极点漫反射的非正交采样基底，统一单位法线的正交基实现。
- 修正 GGX 在 `alpha=1e-4, NoH=1` 附近丢失 alpha² 的消减问题。旧 FP32 表达式在该点的峰值约为参考值的 31,416 倍。
- 为粗糙介质的宏观全反射保留透射提案支持；拒绝未穿过几何界面的透射，并阻止将其误送入反射缓存响应。
- 合并基础与 EON 余弦响应，稳定 MaxEnt 的小集中度反演和背光尾部，去掉旧闭包说明中的过时接口描述。
- 使用整型定点相位维护 Weyl/蓝噪声旋转，避免大帧号浮点相位丢失小数位；payload flags 直接使用整数位。

折射权重采用 [PBRT 的辐亮度传输与方向 Jacobian 约定](https://pbr-book.org/4ed/Reflection_Models/Dielectric_BSDF)。正交基采用有界符号分母的构造，可参照 [Building an Orthonormal Basis, Revisited](https://www.seanet.com/~myandper/abstract/jcgt17.htm)。实现中的约分另外通过独立数值表达式检查。

## 数值和编译检查

| 检查 | 结果 |
| --- | --- |
| 默认、EON 关闭、POM/天空盒/引导关闭 | 每组 83 个入口，编译和 SPIR-V 验证通过 |
| 现有审计 | 方差、Bures、精度、未知不确定度、实体折射和引导等 8 个脚本通过 |
| CPU 代数 | 100,000 组；Smith 约分最大绝对误差约 5.6e-16，透射约分约 1.6e-15 |
| GPU 生产 GLSL | 65,536 组参数；正交基、采样、反射、透射、分支概率与长帧号随机数检查通过 |
| VNDF 积分 | 3 个粗糙度/视角配置，各 262,144 次采样，与独立半球求积的接受概率和能量一致，使用统计容差 |
| Payload 编解码 | 65,536 组、全部 16 种 flags；距离与 FP16 转换精确一致 |

GPU 算术执行设备为 NVIDIA GeForce RTX 4060 Laptop GPU，OpenGL 驱动标识 `4.3.0 NVIDIA 610.62`。这些测试直接调用生产模块，但没有执行 Minecraft/Vulkanite 的光线遍历。

正交基最大误差约 1.6e-7，方向采样逆 CDF 最大误差约 3.9e-7，反射解析响应约 3.1e-7。完整窄峰 PDF 对 FP32 方向归一化误差仍敏感：随机用例最大相对差约 0.81%，检查采用由分布分母推导的条件误差界；相同标量输入下的 D 求值另行检查。临界折射角使用绝对权重误差预算，观察到最大误差约 5.6e-5。

## 静态资源与 GPU 微基准

RGA 2.14.2 的 Vulkan 离线后端，目标 `gfx1100`。表中是独立计算核的编译结果，不是 RT 管线寄存器数。

| 计算核 | 基线 ISA 字节 | 当前 ISA 字节 | 基线 VGPR | 当前 VGPR |
| --- | ---: | ---: | ---: | ---: |
| 反射 BRDF/PDF/响应 | 1200 | 588 | 26 | 15 |
| 采样透射权重 | 892 | 688 | 21 | 18 |
| 方向引导采样/PDF | 568 | 528 | 18 | 18 |

三种核都没有寄存器溢出。引导核 SGPR 从 8 增至 10；反射、透射核维持 14。完整 `composite81` 的 ISA 从 73,508 字节降至 73,440 字节，VGPR 从 81 增至 82，SGPR 保持 86，仍无溢出；这个阶段没有显示明显的静态收益。

RTX 4060 微基准每次 262,144 个调用，8 次重复，共 21 轮，基线/当前版本交替执行并取中位数。数据含 SSBO 输入输出，且重复运行可利用缓存。

| 计算核 | 基线 ms | 当前 ms | 耗时变化 |
| --- | ---: | ---: | ---: |
| 反射 | 0.017792 | 0.016768 | -5.8% |
| 透射 | 0.017920 | 0.016640 | -7.1% |
| 引导 | 0.016640 | 0.016512 | -0.8% |

引导核差异很小，不能据此断言有稳定的实际收益。上述结果也不能换算成整帧 FPS：遍历、材质纹理、分支分歧、缓存命中及降噪成本均未在该微基准中计时。

原始结果位于 `temp/transport_math/report.json`、`temp/transport_benchmark/`、`temp/pipeline_audit/` 和 `temp/refactor/`。`tools/benchmark_transport.py` 可从指定 git 基线重新构造对照源码。

## 渲染适用范围

本轮保持屏幕缓冲布局、RT 分组和降噪读写顺序。数学核的修正不使整个实时渲染器成为无偏参考积分器：缓存终止、能量裁剪、时空滤波、共享色度和主折射的几何端点近似仍存在。主折射 PSR 沿几何界面追踪，不等同于完整粗糙 BTDF 的随机积分。

尚未完成游戏内相同场景、相同相机的长时间录制与整帧性能比较。需要关注太阳边缘、法线贴图近极点、水下临界角、玻璃背后的反射，以及切换配置后的历史收敛。着色器代码中不加入未公开稿件路径、作者身份关联或稿件文本；原有许可证不改写。
