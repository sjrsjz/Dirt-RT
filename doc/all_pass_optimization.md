# 全流程整理与优化

本文保留此前全流程整理的基线、实现与测量记录。文中的缓冲数量、中间输出和性能数字以当时快照为准；当前 scratch 图像复用、末级提案生命周期及诊断写入裁剪见 [1080p profile 优化记录](bench1080_optimization.md)，不同基线的收益不能相加。

这轮以完成 PT 整理后的源码为对照，覆盖降噪、缓存、合成、光栅、辉光和曝光。对照快照位于 `temp/allpass/baseline_shaders/`，与上一轮 PT 微基准的 Git 基线不同。没有引入未公开稿件身份、文件路径或推导文本；保留原有许可证。

## 降噪的数据与数学约束

已撤销按信号域关闭虚拟平面及改变工作组大小的特化。两类信号均使用小步长 16×16、大步长 8×8；粗糙度由输入数据决定，邻居处理、权重及估计量传播共用一套实现。两条估计量分支仍分别累计自己的距离。

中心 PSD 投影及其标量根只准备一次；稳定的有理化距离公式不变。方差瓦片使用非负距离的符号位表达有效性，负零先规范化；无效邻居在读取未初始化矩之前被拒绝。方向保留原有八面体量化，再于装载阶段解码为 vec3，与距离一起存入 vec4。这样用额外共享存储消除每个有效输出最多 49 次重复解码，而没有改变邻域权重或方差公式。详见 [统一降噪优化记录](unified_denoiser_optimization.md)。

原始二阶矩、Kish 有效样本数和估计量标准差继续保持各自含义：不重复除以样本数，不把未知方差当成零，不让空间输出污染原始时域二阶矩。相关性闭合及自适应权重仍是现有近似，其统计校准需求见降噪 README。

| 漫反射大步长 54 | 6088 → 5972 | 79 → 75 | 2048 → 2048 |
| 反射时域 61 | 24280 → 23992 | 101 → 100 | 0 → 0 |
| 反射方差 65 | 13080 → 11016 | 57 → 58 | 11776 → 13824 |
| 反射小步长 66 | 5460 → 5324 | 79 → 75 | 0 → 0 |

## GPU 数值与计时

设备为 RTX 4060 Laptop GPU，OpenGL 驱动 610.62。`tools/audit_post_pipeline.py` 展开并执行真实生产 compute shader，适配描述符语法及图像绑定；输入为合成数据。无 Minecraft 场景或光线遍历计时。

在 257×145 和 1280×720 下，12 个空间 pass 的提案及独立当前帧输出逐位一致；完整时域→方差→六级空间→resolve 链路的 25 份中间/最终图像及 SSBO 对照也逐位一致。测试包括天空、深度边缘、零/中/全粗糙度、未知及无效 sigma、HDR、非整工作组尺寸和两个分支不同的虚拟距离。另有负零距离回归。

65,536 组实际 GLSL 检查中，RIS 历史选择频率 0.751297，理论值 0.75；首候选、全黑样本计数和归一化通过。色调映射改动前后最大绝对差为零。辉光最大缩放误差约 5.2e-7，曝光相对差约 4.4e-5，湿度更新符合修正后的指数响应。

此前按域特化的降噪性能数字已撤下。新方差优化以恢复统一架构、保留此前共同优化的中间版本为基线；1280×720 下测量 31 对，每次查询包含 8 次 dispatch。下表按逐对加速比中位数换算耗时变化。非降噪行保留此前全流程基线的测量，因此不能与方差行合计：

| 阶段 | 观测耗时变化 |
| --- | ---: |
| 共用方差内核：漫反射 50 | 约 -41% |
| 共用方差内核：反射 65 | 约 -39% |
| 空间滤波共用代码抽取 | 静态成本不变，不计性能收益 |
| 辉光横/纵 | 约持平 / -2.9%，差异较小 |
| 曝光 | 约 -33%，约 0.0092 ms → 0.0061 ms |

笔记本 GPU 的调度与时钟仍有波动，尤其大步长滤波；小幅差异不视为稳定收益。这些是独立 dispatch 测量，不能相加推算整帧 FPS。

## 重现与限制

```powershell
python -B tools/audit_shader_pipeline.py --label unified_final
python -B tools/audit_shader_pipeline.py --label unified_eon_off -D EON_ENABLED=0
python -B tools/audit_post_pipeline.py --baseline-dir temp/allpass/baseline_shaders
python -B tools/audit_post_pipeline.py --baseline-dir temp/unified_denoiser/restored_shaders --label unified_denoiser --width 1280 --height 720
```

默认、EON 关闭、引导及额外天空功能关闭三种配置均完成 82 个入口的 GLSL 编译与 SPIR-V 校验，共 246 个；保留字扫描通过。原有八项数学/统计/接口审计通过。大尺寸 GPU 测试应独占运行，避免多个 GPU 审计互相干扰。

原始产物在 `temp/allpass/`；本次统一架构修正产物在 `temp/unified_denoiser/`、`temp/pipeline_audit/unified_*`。基线必须是改动前的完整 shader 目录；没有该快照时不应把当前源码自比较当成回归验证。尚未完成游戏内运动场景、视觉长序列与整帧性能采集，因此不声称整个实时近似渲染器已被证明无偏或达到全局最优。
