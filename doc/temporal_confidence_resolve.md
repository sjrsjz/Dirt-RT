# 实验性置信域时域解算

本试验针对亮点被自适应时间权重放大、随后长时间残留的问题。修改前回退点为 `892a822`。漫反射与反射共用 `temporal_confidence.glsl`，不改变 SSBO 大小。

实景反馈：启用后出现明显噪声回归，已默认关闭。实验 resolve 以 5×5 原始分组替换了 A-Trous 最终 current，CPU 同空间支持的时间实验未覆盖这项系统变化；编译成功不能验证实景降噪质量。后续改动需要保留原 A-Trous 输出，单独验证时间策略及其统计近似。

回退后的第二项修正：旧响应尺度一度保留为 0，导致有效历史只以 `1/(N+1)` 更新，新遮挡阴影响应缓慢。现将 `MAXENT_TEMPORAL_RESPONSE_DISTANCE_SCALE` 恢复为 0.005，重新启用旧光照变化响应。原先的亮点选择偏差仍存在；此次参数修正不代表该问题已解决。

## 使用与范围

- `MAXENT_TEMPORAL_CONFIDENCE_CLAMP=1`：启用失败的实验分支，仅供复核。
- `MAXENT_TEMPORAL_CONFIDENCE_CLAMP=0`：原 A-Trous current + Bures 响应链，当前默认。原 `MAXENT_TEMPORAL_RESPONSE_DISTANCE_SCALE` 只影响此模式。
- `MAXENT_TEMPORAL_CONFIDENCE_FAILURE_PROBABILITY=0.01`：名义概率阈值；增大时更容易投影历史。设为 0 只关闭投影，保留分组、增益约束和新方差语义。

重载 shader 后测试。两种模式使用不同的历史签名，切换时丢弃不兼容历史。

当前 resolve 改为 5×5 原始邻域，其末端空间支持与原六级 A-Trous 不同。A-Trous 仍执行，继续服务漫反射 path guide、诊断和旧模式。此次没有删掉这些调度，也没有 GPU 性能测量。最终光照 BRDF decoder 保持不变。

## 数据流与统计假设

resolve 读取不可变的当前帧原始光照；它不读取邻居正在提交的历史。

5×5 邻域按相对坐标的棋盘奇偶分成检测组与当前组。中心属于当前组。检测组再按相反半平面分成两个不重叠的检查子组。原始输入位置互不重叠；只有在局部同分布、路径随机量独立时，它们才是统计独立的估计。

权重只依赖固定 Gaussian 核（sigma=1）、表面平面距离和几何法线。法线点积低于 0.95 拒绝。反射额外要求材质 ID 相同、GGX alpha 差不超过 0.02。亮度、方向矩和 hit distance 不决定分组权重。视图边界直接排除越界 tap，不复制边界样本。

真实照明边界、镜面反射中的高频结构、PT/ReSTIR 的跨像素相关性会偏离局部同分布独立模型。这些因素需要实景验证。当前组采用几何滤波，因此可能比原 A-Trous 模糊细节；本试验没有宣称保持原空间重建质量。

## 矩方差与接口

对单方向样本 `X=(R u,R)`、`|u|=1`，有恒等式：

\[
\operatorname{tr}\operatorname{Cov}(X)
=2E[R^2]-\|E[Ru]\|^2-E[R]^2.
\]

已组合的方向包满足 `|v_sample|<=w_sample` 时，`2 E[R²]` 给出其二阶范数上界；不能把上界误称为该包的精确方差。原始历史先验采用这一上界闭包。邻域内部的离散样本方差则直接累加 `dot(m_sample,m_sample)`，并用 `1-sum(a_i²)` 作固定权重修正。

原始矩历史使用固定 alpha=0.01（几何重投影损失可提高权重），统一更新均值、二阶矩与 Kish 计数。置信域决策不参与这条人口矩历史的选择。当前与检测估计的噪声尺度取原始历史先验和检测组样本方差的较大值。当前组亮度及其样本方差不参与增益计算。

| 对象 | 方差槽含义 | 样本数 |
| --- | --- | --- |
| 原始矩历史 | `sqrt(E[R²])` | 原始 Kish 计数 |
| 方差准备 / A-Trous | Bures 局部观察方差的平方根 | 保留原空间传播 |
| 新 filtered history / 重投影 scratch | 四维线性矩估计器 trace 方差代理的平方根 | 固定为 1，保持现有 ABI |

新 resolve 不再对 filtered history 方差除一次 Kish 数。重投影继续线性平均各 tap 的方差；在各 tap 方差正确、未知交叉相关性的固定权重模型下，它是保守的重建上界。漫反射 footprint 损失直接膨胀估计器方差。不同空间语义的方差槽不会交叉送入新统计检验。

## 检测、投影与增益

已知总体方差、无偏独立估计及场景不变时，`D=|A-H|²` 满足：

\[
P\left(D>(T_A+T_H)/\delta\right)\le\delta.
\]

运行时使用估计方差，并且历史受先前自适应投影影响，因此 delta 是名义阈值。它不是已证明的实景误触发率。每帧反复检测也不提供整个序列的同等错误概率保证。

检测组的两个子组必须分别超出各自阈值，并且相对历史的变化向量内积为正。这个附加检查避免单个检测组亮点独自触发响应。满足检查后，历史沿 `H -> A` 投影到半径 `sqrt((T_A+T_H)/delta)` 的球边界。所有六个均值分量使用同一个凸组合，保持方向矩的可实现域。

投影后的方差代理使用固定系数下的相关性包络，加上两个假设均值之间的离散项：

\[
P_c=((1-\beta)\sqrt{P_H}+\beta\sqrt{P_A})^2
+\beta(1-\beta)\|A-H\|^2.
\]

这是自适应投影后的工程代理。其固定系数包络不构成对数据相关 beta 的精确方差证明。

独立新旧估计的最小方差标量增益是 `P_c/(P_c+P_C)`。运行时将它约束到：

\[
K_{min}=0.01,\quad K_0=\max(0.01,1/(1+N_{raw})),\quad
K_{max}=K_0+(1-K_0)\beta.
\]

几何重投影失效可进一步提高最低增益。这个上界是防止低估方差时过量写入样本的安全约束。稳定成熟历史且没有变化证据时，增益收敛为固定 0.01；只有独立检测证据支持变化时才放宽上界。

最终方差按 `(1-K)² P_c + K² P_C` 传播。数据相关 beta/K、估计方差与跨像素相关性使整个实际管线保留模型近似；本试验不声明无偏或精确 MC 方差。

## 可复现实验

在 shaderpack 根目录运行：

```text
python -B tools/audit_temporal_confidence.py --compile
```

结果保存于 `calibration/temporal_confidence.json`，包括固定种子 906202609、Python/NumPy 版本、源码哈希、逐时间检查点以及两种模式各 11 个 shader 入口的编译记录。编译通过 Vulkan SDK glslang、AMD half-float 宏进行 SPIR-V 语法验证；未冒充 Minecraft/Iris 驱动实测。

CPU 时间实验：2048 个独立像素，1000 帧，固定方向、均匀平面。新旧时间策略接收相同的分组当前估计，隔离空间支持差异。旧策略使用已知局部 Bures 方差和响应尺度 0.005；新默认策略模拟 FP16 历史均值、RMS、sigma 和原始计数。没有模拟几何、重投影、光照复用或 GPU flush-to-zero。

| 输入分布 / 真均值 | 旧响应均值 / RMSE | 新默认均值 / RMSE |
| --- | --- | --- |
| 99.9% 为 1，0.1% 为 100 / 1.099 | 1.652796 / 0.848064 | 1.118192 / 0.093608 |
| 指数分布 / 1 | 1.038858 / 0.069527 | 0.999518 / 0.029352 |

长尾实验中新策略仍有约 +1.75% 均值偏差。关闭投影但保留 FP16 与相同分组时均值为 1.118021，说明此次残余偏差不能主要归因于投影。oracle 方差、未量化版本为 1.103093；这不是单因素量化归因实验。

保留的不利消融：单检测组即使使用 oracle 方差也可得到 2.070703 的均值；没有增益上界的 plug-in FP16 版本最大值达到 26.3125。两者说明只替换一个显著性公式不足以解决选择偏差。

确定性序列：正常值 1、单帧中心样本 100，第一次写入后为 1.320791，120 帧后为 1.096039；亮点仍按线性平均保留贡献。两个检测子组共同看到的 1→100 / 100→1 阶跃，第一帧分别达到 99.999900 / 1.000100。这是低噪声平面测试，高噪声变化响应会更保守。

## 实景试用清单

1. 固定相机观察原噪点场景：比较两模式的亮点最大值、残留与整体曝光。
2. 切换光照、移动视角：检查阶跃响应、拖影和解遮挡。
3. 检查镜面、水面、玻璃、细小光源及明暗边界：确认 5×5 几何滤波的细节损失是否可接受。
4. 测量整帧开销。此版本每域 resolve 新增最多 25 个几何/原始样本读取，尚未消除旧空间管线的重复工作。
