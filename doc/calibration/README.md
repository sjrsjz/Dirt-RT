# 平面上的 Bures 方差传播标定

本实验针对 Dirt RT 六级 A-Trous 的独立 current 分支，重新标定 Kish 有效样本数传播中的常相关系数。几何假设为正视、平整、同一表面，所有几何拒绝指数取零。光照采用空间均匀的联合 alpha=1 分布，以独立路径样本产生空间噪声；保留实际 Bures 信号拒绝、逐级置信度尺度、FP16 信号与标准差打包，以及每像素旋转的 Poisson tap。

## 可复现入口

在 shaderpack 根目录执行：

    python -B tools/calibrate_bures_pass_correlations.py

默认配置生成 bures_plane_correlations.json，包含配置、设备和软件版本、源文件哈希、逐场逐级结果及独立 MC 重复采样结果。脚本从 shader 读取当前灵敏度、方差准备参数和逐级置信度。旧系数作为固定核基线保留在脚本中，安装新系数后仍能复现同一比较。

标定覆盖 \(\kappa=0,0.7,0.98\) 和等权历史 \(N=1,4,16,64\)，两域灵敏度均为 0.5。每组使用 4 个训练场、8 个留出场，共 48 个训练场和 96 个留出场。每场大小 \(256^2\)，使用周期边界；尺寸大于六级核的两倍最大累积支持半径，避免自重叠别名。每场另生成 128 个独立 Rademacher 误差探针。主种子为 9062026，留出场与训练场的信号和探针种子互不重合。

## 系数含义

一组非负归一化 tap 权重记为 \(a_i\)，前一级预测归一化方差为 \(q_i=1/N_i\)。运行时常相关闭包为

\[
q_{\rm out}=D+pC,\qquad
D=\sum_i a_i^2q_i,\qquad
C=\left(\sum_i a_i\sqrt{q_i}\right)^2-D.
\]

固定当前信号产生的权重，让独立单位方差误差探针通过同一个累积滤波算子，测量 \(Q_{\rm out}\)。每级按训练场、像素等权聚合：

\[
p=\frac{\sum(Q_{\rm out}-D)}{\sum C}.
\]

前一级使用已经标定的全局常数递归传播 \(q_i\)，因此结果直接匹配 shader 的递归接口。首级输入相互独立，严格取 \(p=0\)，且首级参考方差用 \(\sum a_i^2\) 精确计算。后五级由随机探针估计核重叠。Kish 字段按运行时格式做 FP16 舍入。

这些值是声明测试域上的有效常数。真实信号权重的数据依赖性另外通过 MC 重复采样检验。作为独立检查，把灵敏度设为零后，本脚本恢复固定核参考；六级系数的最大绝对差约 0.0013。

## 安装结果

| A-Trous 步长 | 固定核基线 | Bures 权重标定 |
|---:|---:|---:|
| 1 | 0 | 0 |
| 2 | 0.10600873 | 0.09184833 |
| 4 | 0.14116979 | 0.12613998 |
| 8 | 0.13941258 | 0.13781854 |
| 16 | 0.14705113 | 0.14262104 |
| 32 | 0.15253123 | 0.14655028 |

系数写入 shaders/lib/lighting/denoiser/internal_constants.glsl，漫反射和反射共用。MC 观测方差继续线性过滤，常数作用于与其配对的 Kish 有效样本数。

在独立留出场上，末级预测方差与独立探针参考的聚合比值由旧系数的 1.16082 改为 0.99855。逐场比值范围为 0.86728–1.19703，逐场平均绝对相对误差为 5.15%；一个常数仍近似了不同集中度和历史长度的核。

## 完整 MC 方差核验

独立 current 使用产生时域均值的最后一个原始样本，因此保留了真实路径中的信号与权重依赖。每个参数组合在同一像素坐标重复 8 次，按重复样本均值中心化，再用 \(1/(8-1)\) 估计局部 Bures 二次型下的中心方差。Poisson 的坐标哈希固定，路径样本独立。

新系数在首级的预测/中心 MC 方差比为 0.93491，末级为 0.91140。初始方差闭包和权重选择已带来部分低估。对每个参数组合用首级比值归一化，以单独查看后续传播，末级比值从旧系数的 1.13544 改为 0.97665。

每参数组合的末级原始预测/中心 MC 方差比范围为 0.73305–1.17172。该结果界定了这次标定的精度：重叠传播得到改善，有限历史的初始方差闭包仍需校准。结果同时保留相对精确目标的 Bures MSE、局部二次型 MSE 和场均值残差；它们包含滤波偏差，未用于相关系数拟合。

改变灵敏度、逐级置信度、方差准备策略或 tap 模式时应重新运行标定。几何边缘、非均匀光照、任意路径分布和自适应时域权重的外推精度需要单独测量。此实验采用 PyTorch/CUDA 计算统计量，不是 GPU shader 性能基准。
