# 异常方差入口隔离

本次只修复异常统计量进入滤波的问题，保持 Bures 闭包、Kish 公式、相关系数、拒绝强度及 SSBO 大小不变。

## 状态与行为

复用现有 FP16 sigma 通道：

| sigma | 含义 | 行为 |
| --- | --- | --- |
| 有限非负且可存储 | 有效方差估计 | 使用原来的方差和拒绝公式 |
| -2 | 光照有效，方差未知 | 保留光照，不参与方差池化；端点未知时跳过光照拒绝项 |
| -1 | 光照／表面无效 | 保持原有无效表面处理 |

1. Prepared 检查一阶矩、RMS、有效样本数，排除非有限、负值、零均值但非零 RMS、明显违反矩锥／RMS>=mean 的状态。矩边界容许 FP16 量级的舍入误差。
2. 有效邻域继续在线性矩空间池化。中心时域估计无效时采用空间估计；空间估计无效而中心有效时采用中心估计；都缺失时写 -2。原来的 `65504²` 和用户定位时使用的 `1.0` 替代值已移除。
3. A-Trous 的光照均值与 Kish 仍使用接受的光照权重；方差只使用有效方差贡献，并按其权重重新归一化。无有效贡献时保持 -2。几何拒绝保持启用。
4. 双线性历史重投影、反射 surface/virtual 混合及 filtered-history 回写保持相同未知语义，不会将 -2 平方成4或裁成0。
5. 时域响应任一端方差未知时，不使用方差驱动的响应增益，采用 `max(重投影下限,1/(1+Raw_N))`，避免退回0权重后冻结。
6. 打包前的非有限历史矩不会被清空一阶状态后仍以有效 N 携带 RMS；Raw 漫反射单包 RMS 与清洗后的同一包亮度一致。反射与漫反射的历史 tap 在累加前检查其有限性。

有效邻域恢复是局部统计可转移的回退，并不是缺失方差的精确推断。此改动也不解决此前审计中的一般合并包闭包误差或异方差 Kish 乘积近似。

## 显示与重载

Prepared 和 Filtered 的未知方差显示为中性灰；原有无效值仍为品红色。
灰色不是零方差。合法高方差仍按原色标显示，未新增按画面亮度裁尾的阈值。
有限可表示域上限由 FP16 sigma 存储决定，超出表示域也进入未知状态。

更新了两域历史签名，重载后拒绝旧方差语义的历史，避免遗留巨大常数继续传播。没有增加 SSBO、纹理或通道。

## 验证

`python -B tools/audit_uncertainty_ingress.py --compile`

- CPU 故障注入覆盖非有限数、负标记、孤立残余 RMS、矩锥失配、未知／有效混合、全未知但有效光照和零权重端点。
- 10000 组有限方差混合与原线性平均公式比较，最大相对误差约4.02e-16（CPU double）。
- FP16 标记往返通过；合法方差1e8保留；N=199且未知方差时的基础时域权重为0.005。
- 43 个生产 shader 变体通过 glslang SPIR-V 编译：22 个时域／空间关键 pass 的两模式变体、9 个其余计算 pass、4 个方差调试 fragment、ray0..ray7。
- 这是源码编译和 CPU 行为模型验证，尚未验证真实游戏画面或 GPU 运行时性能。
