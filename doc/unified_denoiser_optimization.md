# 统一降噪内核优化

本文是恢复统一降噪架构及方差瓦片优化的历史记录，以下数据对应当时的 1280×720 合成基准。当前统一架构下的 scratch 存储、末级输出与最新验证见 [1080p profile 优化记录](bench1080_optimization.md)；本页不代表当前缓冲调度或新增改动的收益。

漫反射与反射共用方差准备、空间权重和估计量传播。已撤销按域关闭虚拟平面的宏及漫反射独有的工作组设置；两类信号的小步长均为 16×16，大步长均为 8×8。粗糙度作为数据输入参与同一个算法。

## 实现

- `variance_prepare.glsl` 保留矩有效性、方差闭合和阶段调度；`variance_tile.glsl` 管理共享瓦片及 7×7 空间矩重建。
- 瓦片装载时解码方向，将方向与径向距离存为 `vec4`。每个有效输出最多 49 次方向解码，变为每个有效瓦片元素一次。保留原有八面体量化和 FP32 运算顺序，避免把存储优化混入数值模型变化。
- 有效标记仍复用距离符号位；负零先规范化。无效邻居先拒绝，再读取其余共享字段。
- `atrous_tap.glsl` 集中大小核的邻居有效性、权重和双估计量更新。它作为循环体包含，保留原来的 `continue` 控制流；实测将这些内容改成带提前返回的函数会增加 NVIDIA 大核耗时，因此没有采用该版本。
- 保留此前共用的中心距离度量预计算、未知不确定度语义及时域校验简化。

空间提案和独立当前帧继续使用同一组权重，分别传播自己的信号、标准差及虚拟距离。没有修改原始二阶矩、Kish 样本数、相关性闭合、持久缓冲 ABI 或历史提交顺序。

## 同架构对照

本次基线为 `temp/unified_denoiser/restored_shaders/`：已经恢复统一架构，并保留此前共同优化，但尚未移动瓦片方向解码。这样比较得到的收益来自统一内核本身。此前全流程基线仍在 `temp/allpass/baseline_shaders/`；两种基线不能混用计算增量收益。

RTX 4060 Laptop，OpenGL 610.62，1280×720 合成数据。执行完整生产 compute pass，预热后交替测量 31 对；方差计时每次查询执行 8 次，结果换算为单次 dispatch。以下降幅由每对加速比的中位数计算，不能直接用两个独立耗时中位数相除替代。

| 方差 pass | 基线耗时中位数 | 当前耗时中位数 | 成对耗时降幅 |
| --- | ---: | ---: | ---: |
| 漫反射 composite50 | 2.059 ms | 1.469 ms | 约 41% |
| 反射 composite65 | 2.547 ms | 1.263 ms | 约 39% |

时钟与调度波动较大：50 的基线/当前 P10–P90 为 1.299–3.534 / 0.768–1.996 ms；65 为 1.259–3.291 / 0.757–2.003 ms。仅将结果视为该设备、合成输入下的独立 pass 证据，不外推游戏帧率。

RGA 2.14.2、gfx1100 离线编译的同架构对照：

| Pass | ISA 字节 | VGPR | LDS 字节 |
| --- | ---: | ---: | ---: |
| 50 | 11144 → 10336 | 49 → 50 | 9728 → 13824 |
| 65 | 11728 → 11016 | 52 → 58 | 9728 → 13824 |
| 51 / 66 | 5324 → 5324 | 75 → 75 | 0 → 0 |
| 54 / 69 | 5972 → 5972 | 75 → 75 | 2048 → 2048 |

上述 pass 均无 scratch 或寄存器溢出。瓦片方向预解码增加共享存储和部分寄存器占用，是明确的资源交换。空间循环抽取没有降低静态成本，不计为性能收益。尚未在 AMD 实机计时。

## 验证

- 默认、关闭 EON、关闭引导及额外天空功能三种配置，共 246 个入口通过 GLSL 编译和 SPIR-V 校验；保留字扫描通过。
- 257×145 对照全流程原始基线，1280×720 对照恢复统一架构的中间基线：完整降噪链路的 25 份图像及最终 SSBO 逐位一致，包括几何与历史元数据。
- 12 个空间 pass 的两个估计量输出均无 FP16 数值变化。测试包含随机表面法线、混合粗糙度、HDR、两分支各自未知的 sigma、无效光照和不同虚拟距离。
- 同一输入及相同光场敏感度分别经过两个域适配器，六级结果逐位一致。这项检查防止以后把粗糙度数据误换成域分叉。
- 链路测试额外包含倾斜法线、深度边缘、天空、短历史、负零距离和非整工作组尺寸；原有八项数学、统计和接口审计通过。
