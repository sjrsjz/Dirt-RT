# 实体贴图与折射复用修复

2026-09-06。基线检查点：`0dac118`。本次修复保持现有缓冲区容量和 RT 调度。

## 远距离实体

原来的实体 any-hit 和材质采样把整张皮肤视为一个 UV 区域，远处扩大的各向异性采样足迹可以跨入其他面或透明黑区域。实体皮肤的各面通常没有独立的 mip padding。

现在两个路径共用四顶点 UV 包围盒，每个 tap 限制在该面的可过滤范围内。最高 mip 同时受区域尺寸和四条边的 texel 对齐限制；使用较粗一级 mip 的半 texel 内缩，保证三线性采样两级的支持域都留在当前面内。方块 atlas 的重复采样保持原样。退化 UV 的 any-hit 平面法线采用与材质读取一致的几何法线回退。

该边界保证针对 Minecraft 常规的整数 texel 边界实体 UV。自定义模型的非矩形 UV 岛、非常大的皮肤在现有 FP16 payload 中的 UV 舍入，以及真实游戏中的远距离覆盖率仍需单独观察。

## 折射与漫反射几何

漫反射 RT 已经沿原始相机射线跳过水、玻璃等界面，计算其后第一个不透明表面的入射光。但原实现使用 primary 水面的深度和法线做漫反射降噪、历史记录和 PSR 屏幕复用校验。这会让实际光照与几何分属两个表面，导致水下结果被错误拒绝。

现在 `DIF_N_SURFACE` 的空闲位保存对应表面的几何：

| 分量 | 当前内容 |
| --- | --- |
| x 低 16 位 | 原有 Oct8 宏观法线 |
| x 高 16 位 | 新增 Oct8 背景几何法线 |
| y | 原有漫反射颜色与粗糙度 |
| z | 原有运动与有效性 |
| w | 新增 FP32 漫反射命中距离；负值表示无表面 |

不透明 primary 命中继续直接读取原有全精度几何法线。背景位置由相同的相机射线和新增距离重建。时域、方差准备、A-Trous 几何、历史提交、实验性 confidence 分支及 PSR 校验统一使用漫反射域几何；反射和最终 primary 着色继续使用 primary 几何。历史签名更新为 `0x2600`，拒绝旧语义的历史。

PSR 投影遵循原生 RT 的整数像素坐标约定，移除半像素偏移。四个双线性 tap 分别进行边界、距离和法线校验，再归一化有效权重。屏幕外、被遮挡或不满足 PSR 条件的端点保留辐射率缓存回退。
